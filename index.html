Security Finding Specimen

Redacted Security Assessment Report

FINDING ID: VULN-2026-089 CVSS v3.1: 8.6 (High)

Affected Asset

https://api.redacted-target.sec/v1/organizations/{id}/settings

Description

The API endpoint lacks proper object-level authorization checks. Any authenticated low-privilege user can modify organization settings by supplying another tenant's organization ID in the request path.

Proof of Concept

GET /v1/organizations/org_9921/settings HTTP/1.1
Host: api.redacted-target.sec
Authorization: Bearer eyJhbGciOi... (Low Priv User)

Remediation

Validate session ownership inside middleware before processing database updates.
